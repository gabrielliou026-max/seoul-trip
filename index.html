首爾7天
購物美食＋雪景

高雄直飛仁川・12月・住明洞不換飯店

啟強老婆姪女

抵達・明洞暖身夜

下午入住，晚上先感受首爾的冷與熱

  1. 上午

    高雄小港 → 仁川機場

    出發前72小時內填好電子入境卡。落地後在機場買WOWPASS或T-money卡，三人各一張。

  2. 🚌 機場巴士6015・仁川機場（T1/T2皆有站）→ 明洞站・約70–90分鐘（依路況），車上有行李架

  3. 下午

    明洞飯店入住

    三人房選明洞或乙支路一帶，機場巴士6015直達，之後每天出門都方便。

    地圖看照片

  4. 🚶 飯店步行到明洞商圈・約5分鐘

  5. 晚上

    明洞街頭小吃 ＋ 烤肉

    第一晚先吃烤肉暖身，飯後逛美妝店和路邊攤（雞蛋糕、龍蝦串、糖餅）。

    地圖看照片
🍴 必吃推薦：明洞餃子（명동교자，招牌刀削麵＋餃子，開業超過50年的老字號）・起司熱狗・韓式炸雞（치킨）配啤酒

古宮・市場・東大門夜購

上午文化，中午吃市場，晚上逛到深夜

  1. 🚇 從明洞飯店出發：地鐵4號線 명동역 → 충무로역 轉3號線 → 경복궁역（5號出口）・約20分鐘・轉乘1次

  2. 9:00

    景福宮

    穿韓服免門票，雪後的宮牆最好拍。10:00有守門將換崗儀式。週二休館。

    地圖看照片

  3. 🚶 景福宮東側出口步行到北村韓屋村・約10分鐘

  4. 上午

    北村韓屋村 → 仁寺洞

    坡道多，穿好走的鞋。仁寺洞找間傳統茶屋喝柚子茶、雙和茶。

    地圖看照片

  5. 🚇 仁寺洞步行到종로3가역，轉1號線1站 → 종로5가역（8號出口即廣藏市場）・約15分鐘

  6. 中午

    廣藏市場

    綠豆煎餅、麻藥飯捲、生拌牛肉、刀削麵。人多，站著吃也是體驗。

    地圖看照片

  7. 🚶 步行約15–20分鐘（沿鐘路直走），或搭1號線鐘路5街→東大門1站，轉4號線→東大門歷史文化公園站・約10分鐘

  8. 晚上

    東大門DDP ＋ 批發商場

    DDP冬季有燈飾展。Doota、Migliore逛到深夜；批發樓層多為現金、不可試穿。

    地圖看照片
🍴 必吃推薦：廣藏市場「순희네빈대떡」綠豆煎餅・生拌牛肉（육회）・麻藥飯捲・仁寺洞傳統茶屋的柚子茶、雙和茶

南怡島雪景一日

建議直接報一日團，含來回車與三個點

  1. 🚌 明洞出發：一日團遊覽車接送・約1.5–2小時抵達南怡島渡口

  2. 上午

    南怡島

    杉木道下雪時最經典，島上約2小時。渡輪來回，帶手套與暖暖包。

    地圖看照片

  3. 🚌 遊覽車接駁・南怡島 → 江村・約20分鐘

  4. 下午

    江村鐵路自行車

    四人車，三人剛好。沿舊鐵道約40分鐘，風大很冷，圍巾要包好。

    地圖看照片

  5. 🚌 遊覽車接駁・江村 → 晨靜樹木園・約40分鐘

  6. 傍晚

    晨靜樹木園・五色星光燈節

    每年12月至隔年3月左右的燈飾展，天黑後入園最好看，回到首爾約晚上9點。

    地圖看照片
三個點都在京畿道加平方向，自行搭車要轉ITX與公車，帶著長輩與行李不方便，一日團價差不大。
🍴 必吃推薦：加平／春川一帶名物「닭갈비」春川辣炒雞・蕎麥涼麵（막국수）・南怡島園區內烤栗子、烤地瓜

滑雪一日團

三人都是初學也沒關係，團體含教學

  1. 🚌 明洞出發：滑雪團接駁巴士・約1.5小時抵達雪場

  2. 全天

    維瓦爾第Park 或 伊利希安江村

    一日團通常含接駁、雪具、雪衣租借、基礎教學。從明洞出發約1.5小時，下午4點左右回程。

    地圖看照片

  3. 🚌 接駁車返回市區・約1.5–2小時，可請司機在新村／梨大附近下車（先跟導遊確認是否可中途下車）

  4. 晚上

    新村・梨大晚餐

    滑完雪吃部隊鍋或雞排（닭갈비）補回體力，這一帶學生餐廳多、價格親民。

    地圖看照片
如果有人不想滑雪，這天可改成愛寶樂園（冬季有燈光秀），或直接當成江南購物日。
🍴 必吃推薦：新村部隊鍋街（부대찌개골목）・辣炒雞排（닭갈비）配起司・滑完雪來一碗熱呼呼的杯麵最對味

弘大・延南洞・漢江

姪女最會喜歡的一天，年輕品牌與咖啡廳

  1. 🚶🚇 從明洞飯店出發：步行約10分鐘到을지로입구站，搭2號線直達홍대입구站・約30分鐘・不用轉乘

  2. 上午

    弘大購物街

    服飾、飾品、文具、唱片行。11點後店才陸續開，不用太早出門。

    地圖看照片

  3. 🚶 弘大步行到延南洞・京義線林道入口・約10分鐘

  4. 中午

    延南洞咖啡廳・京義線林道

    從弘大走過去10分鐘，沿廢棄鐵道改建的公園散步，兩側都是小店。

    地圖看照片

  5. 🚶 沿林道／小路步行到望遠市場・約15–20分鐘

  6. 下午

    望遠市場

    在地人市場，炸雞、辣炒年糕、刀削麵，價格比廣藏便宜。

    地圖看照片

  7. 🚕 建議搭計程車・望遠市場 → 汝矣島漢江公園・約15–20分鐘（地鐵需轉乘2次約35分鐘，晚上帶著長輩改坐車較省事）

  8. 晚上

    汝矣島漢江公園

    在便利商店煮杯麵看漢江夜景是首爾人的日常。太冷可改上63大廈展望台。

    地圖看照片
🍴 必吃推薦：望遠市場可樂餅（고로케）、辣炒年糕・延南洞人氣咖啡廳甜點・漢江便利商店泡麵＋炸雞外送

江南・樂天世界塔

集中採購日，晚上把免稅店逛完

  1. 🚇 從明洞飯店出發：地鐵4號線 명동역 → 동대문역사문화공원역 轉2號線 → 삼성역（COEX）・約30–35分鐘・轉乘1次

  2. 上午

    COEX 星空圖書館

    拍照地標，同棟就是COEX Mall，有大型書店與各種品牌。

    地圖看照片

  3. 🚇 地鐵2號線 삼성역 → 교대역 轉3號線 → 신사역（新沙洞林蔭道）・約20分鐘・轉乘1次

  4. 中午

    新沙洞林蔭道

    設計師品牌與餐廳，價位比弘大高，適合找午餐與逛精品。

    地圖看照片

  5. 🚇 地鐵3號線 신사역 → 교대역 轉2號線 → 잠실역（樂天世界塔）・約25分鐘・轉乘1次

  6. 下午

    樂天世界塔 Seoul Sky

    500公尺高展望台，冬天空氣乾淨能見度好。下面石村湖12月有燈飾。

    地圖看照片

  7. 🚶 同棟商場內，步行即達樂天百貨・免稅店

  8. 晚上

    樂天百貨・免稅店

    免稅品要提早買，機場提貨。百貨地下街晚餐後回明洞。

    地圖
🍴 必吃推薦：新沙洞林蔭道人氣brunch店・COEX美食街多國料理・石村湖畔小吃攤（冬季限定熱飲、烤栗子）

最後補貨・回高雄

退稅單整理好再出門

  1. 上午

    明洞最後補貨

    忘了買的美妝與伴手禮。單筆滿一定金額的即時退稅店家可直接折扣，不必到機場辦。

  2. 🚌 機場巴士6015・明洞站 → 仁川機場・約70–90分鐘（依路況），提早3小時出發較保險

  3. 中午

    仁川機場

    提早3小時到。有退稅單先去海關櫃檯蓋章，再到免稅店提貨處領貨。

    地圖
  4. 晚上

    抵達高雄

    行程結束。

🍴 必吃推薦：離開前到明洞街邊再吃一輪熱炒年糕、雞蛋糕；機場美食街有部隊鍋、拌飯可解決最後一餐

出發前要辦的事

  • 台灣護照在2026年底前免申請K-ETA，但抵達前72小時內要填電子入境卡（e-Arrival Card），三人各填一份。
  • 護照效期6個月以上。
  • 行動電源、暖暖包不能託運，要放隨身行李。
  • 網路：三人各買eSIM，或一張分享器。
  • 換匯：台灣先換一部分韓元，其餘用WOWPASS在當地機台換。

12月穿著

  • 首爾12月平均約 -5～5°C，近郊與滑雪場更冷。
  • 發熱衣＋毛衣＋長羽絨外套，帽子、手套、圍巾必備。
  • 鞋子要防滑，路面結冰很常見。
  • 室內暖氣強，穿脫方便的洋蔥式最好。

三人分工建議

  • 一人管機票、飯店與一日團訂單。
  • 一人管餐廳口袋名單與排隊時間。
  • 一人管退稅單與購物清單。
